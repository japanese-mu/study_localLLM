# localLLM

ローカルLLM運用のメモ置き場。

## 内容
- 32GB RAM / RTX 5070 12GB 環境でのモデル比較
- LM Studio / Ollama の導入メモ
- Qwen / Gemma / Mistral 系の用途別整理
- コーディング・チャット・RAG向けの試行ログ

## 目的
- 自分用の知識整理
- モデル選定の記録
- 将来的な公開用ドキュメントの土台作り

## フォルダ構成
- `models/`: モデル比較と選定理由
- `setup/`: PC環境とセットアップ手順
- `logs/`: 試した結果の記録
- `prompts/`: 再利用したいプロンプト
